# Runnerプロトタイプのセキュリティ

撮影URLと全HTTPリクエストはallowed_originsに一致する必要があります。URL内の認証情報、HTTP(S)以外のスキーム、localhost、Google Metadata、IPv4・IPv6の非公開・予約アドレスを拒否します。DNSが返す全アドレスを検査し、公開IPと非公開IPが混在する場合も拒否します。自動リダイレクトは無効化し、リダイレクト応答は拒否します。リダイレクトしない最終URLをManifestへ指定してください。

Service WorkerとWebSocketを無効化しています。HTTP Basic認証情報は環境変数から読み込み、撮影対象のOriginに限定します。Manifestや結果には保存しません。TLSエラーは無視しません。

ただし、現在のDNS検査とPlaywrightのリクエスト取得時のDNS解決は別処理です。DNS rebindingへの完全な防御は未実装です。Cloud Runへ公開する前に、DNS解決先へ接続を固定する仕組みと、非公開ネットワーク・Metadataへの通信を遮断するネットワーク制限を実装・検証してください。このプロトタイプは信頼できる作成者のManifestを使う開発用です。

ローカルのWordPressも非公開IPに該当するため、現在のRunnerの撮影対象には指定できません。ローカル環境向けの限定許可方式は後続で設計します。汎用的なSSRFガード解除フラグは提供しません。

画像はWordPressへアップロードせず、指定したローカルディレクトリへ保存します。出力ディレクトリの作成権限は0700です。共有Webディレクトリを出力先に使用しないでください。WordPress側の非公開Storage・認証付き画像配信はPhase 3・4で実装します。
